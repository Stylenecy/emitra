# DELEGASI — Qwen: Operation + Business Model Canvas (BMC)

Platform: **Emitra** — AI-Powered Carbon Compliance & Export Intelligence.

## TUGAS: Tulis 2 section

### SECTION 1: Operation (~2 halaman)
1. **Resource Management:**
   - **Location:** Yogyakarta (pusat R&D), sales team di kawasan industri (Cikarang, Cilegon, Karawang)
   - **Initial Infrastructure:** Cloud servers (AWS/GCP), OCR pipeline, database faktor emisi, CBAM report generator
   - **Human Resources:** Tim inti 4 orang + 1 customer success + 1 sales
   - **Production Process:** Order fulfillment flow — client signup → onboarding (data mapping, training) → monthly data ingestion → quarterly report generation → audit trail update
2. **Risk Assessment — Operational:**
   - Dependency on cloud infrastructure → mitigasi: multi-region backup
   - Data inconsistency from client → mitigasi: AI validation layer + manual review
   - Regulatory updates from EU → mitigasi: dedicated regulatory monitoring team
3. **Legal:**
   - Perpres 98/2021 (NEK)
   - POJK 14/2023 & 18/2023
   - ISO 27001 certification (target year 2)
   - Partnership with accredited verifier (Sucofindo/Mutu Agung/SGS)
